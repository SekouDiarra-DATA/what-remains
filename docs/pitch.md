# Script de pitch / vidéo de démo (2 minutes)

> À remplir le jour du hackathon. Objectif : un script minuté pour ne pas dépasser 2 minutes.

## Structure suggérée (2 min = ~300 mots à débit normal)

### 1. Accroche — le problème (20-25s)
- Quel outil du quotidien / quel contexte ?
- Quelle friction concrète vit l'utilisateur aujourd'hui ?

### 2. La solution en une phrase (10-15s)
- "Notre agent [nom] vit dans [canal/contexte] et fait [action] pour [utilisateur cible]."

### 3. Démo live (60-70s)
- Scénario utilisateur pas à pas (montrer, ne pas raconter)
- Insister sur ce qui ne serait pas possible avec un chatbot classique dans une fenêtre séparée
- Montrer le contexte réel utilisé par l'agent (données, canal, historique...)

### 4. Pourquoi le contexte compte (15-20s)
- Ce que l'agent sait/fait grâce à son intégration dans cet environnement précis

### 5. Stack technique en une phrase (5-10s)
- Outils/sponsors utilisés

### 6. Clôture (5-10s)
- Nom du projet + équipe + appel à l'action (lien repo)

## Notes de tournage
- Filmer en premier le scénario qui marche à coup sûr (fallback si bug live)
- Sous-titres recommandés si présentation multilingue
- Vérifier le son avant l'enregistrement final
